# MySQL Concepts Practice

This repository contains my practice code for learning and understanding MySQL and its core database concepts. It includes hands-on examples of database creation, table management, SQL queries, CRUD operations, relationships, and data manipulation.

## Technologies Used

* MySQL
* SQL

## Concepts Covered

* Database and table creation
* Data types and constraints
* INSERT, SELECT, UPDATE, and DELETE
* WHERE, ORDER BY, GROUP BY, and HAVING
* Aggregate functions
* Primary Key and Foreign Key
* Joins
* Subqueries
* Relationships between tables
* SQL operators and functions
* Basic data filtering and sorting

## Purpose

The purpose of this repository is to practice **SQL and MySQL concepts** through hands-on coding and develop a strong foundation in relational databases.
